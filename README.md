# CAT 43.3 — Sprint 4

Aplicación de renting automotriz desarrollada con Angular.

En este Sprint 4 el proyecto evoluciona hacia una aplicación híbrida móvil mediante Ionic y Capacitor, manteniendo Firebase como backend principal.

## Tecnologías utilizadas

- Angular
- Ionic
- Firebase Authentication
- Cloud Firestore
- Capacitor
- Android Studio

## Funcionalidades principales

- Registro de usuarios
- Inicio de sesión
- Recuperación de contraseña
- Lectura dinámica de vehículos desde Firestore
- Pantalla detalle de vehículo
- Gestión de favoritos
- Integración Android mediante Capacitor
